# ShikshaSync

Offline-first adaptive learning PWA for rural multi-grade schools.
Runs on-device BKT math and reading drills in English, Kannada, and Hindi, caches voice hints locally, and syncs compact remedial packs when online.

Optional environment variables: `ELEVENLABS_API_KEY`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`, `AWS_DYNAMODB_TABLE`, `AWS_BEDROCK_MODEL_ID`.

```bash
npm install && npm run dev
```
